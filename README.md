# iGoogle revival

A dependency-free, functional revival of Google's customizable iGoogle homepage.

Features include persistent tabs, suggested gadgets, one-to-three-column layouts, drag-and-drop organization, nine themes, canvas views, custom RSS feeds, live weather and news, productivity tools, games, and Google service shortcuts.

Open `index.html` directly, or run `docker build -t igoogle .` then `docker run --rm -p 8080:8080 igoogle`.

This independent nostalgia project is not affiliated with Google.
